# dotfiles-bootstrap

Thin public launcher for private `vincent-freeman-labs/xiao-he` dotfiles.
No secrets inside — only the private repo's path. Downloading works for
anyone; installing requires read access to xiao-he.

New Mac, one line:

```bash
curl -fsSL https://raw.githubusercontent.com/vincent-freeman-labs/dotfiles-bootstrap/main/install | bash
```

Details (update, verify): xiao-he `infra/dotfiles/docs/onboarding.md`.
